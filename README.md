# Gemini Web Chat Exporter

将本机 Google Gemini 网页端对话导出为 Markdown 文件的 Windows 只读导出工具。

它支持通过浏览器远程调试端口（CDP）只读扫描当前打开的 Gemini 标签页、左侧边栏的置顶对话与最近 5 个对话，以及独立的 Gemini Notebook（笔记本）对话；同时也支持直接解析普通浏览器保存的网页 HTML 文件或系统剪贴板内容，让用户从编号菜单中选择需要导出的会话。

## 功能

- 自动扫描开启远程调试端口的 Chrome 中的 Gemini 会话标签页。
- 自动只读提取 Gemini 左侧边栏的「全部置顶对话 + 最新 5 个对话（自动去重）」，避免拉取上千条陈旧历史记录，并内置 5 分钟本地列表缓存。
- 支持导出独立的 Gemini Notebook（笔记本）会话链接，导出成功后自动提取真实网页标题并加入本地常驻收藏菜单。
- 内置一键启动专属调试模式 Chrome 窗口选项（`[B]`），无需手动配置命令行参数。
- 支持免调试端口模式（`[H]`）：直接拖入普通浏览器保存的 `.html` 网页文件，或直接读取系统剪贴板中的 HTML 源码与纯文本。
- 自动识别系统剪贴板中的 Gemini 会话链接（`[C]`），支持一键提取。
- 支持「简洁模式」（仅导出用户消息与模型最终回复）与「详尽模式」（额外导出模型思考过程 `model-thoughts`）。
- 动态计算代码块反引号围栏长度，完整保留代码缩进、制表符、行内代码与列表层级。
- 导出为桌面的 `Gemini_Chat_Export.md`（或 `Gemini_Chat_Export_Detailed.md`），并自动将完整内容复制到 Windows 剪贴板。
- 全程只读采集：零 JavaScript 注入（不使用 `Runtime.evaluate`）、不抢占窗口焦点、不修改或删除任何云端与本地对话数据。

## 系统要求

- Windows 10 或 Windows 11。
- Windows PowerShell 5.1 或更高版本。
- Node.js 22 或更高版本（使用内置全局 `WebSocket` 与零第三方依赖内核）。
- Google Chrome 浏览器（如使用自动扫描置顶/近期对话或 URL 导出功能）。

可在命令行检查 Node.js 是否可用：

    node --version

如果没有显示版本号或版本低于 v22，请先从 [Node.js 官方网站](https://nodejs.org/) 安装最新 LTS 版本。安装时请确保勾选添加到 `PATH`。

## 使用方法

1. 在本仓库页面点击绿色的 `Code` 按钮，选择 `Download ZIP` 并解压到任意位置。
2. 双击运行：

    运行-导出Gemini对话.cmd

3. 根据提示选择导出模式：
   - 输入 `y` 开启详尽模式（包含模型思考过程）；
   - 输入 `n` 使用简洁模式（仅包含用户消息与模型正式回复）。
4. 若首次使用且尚未开启带调试端口的 Chrome，可在菜单中输入 `B` 回车，工具会自动打开一个专属 Chrome 窗口。在该窗口登录一次 Google Gemini 后回到终端按回车刷新菜单。
5. 在会话列表中输入目标会话前的数字编号，例如：

    1

6. 导出完成后，在桌面找到：

    Gemini_Chat_Export.md

导出的完整 Markdown 内容也会自动复制到 Windows 剪贴板。

## 会话列表说明

会话列表会按三个分组显示可导出的会话：

    第一组｜当前已打开的标签页
     [ 1] [当前已打开标签页] 项目架构讨论  端口 9222 · 12 轮

    第二组｜置顶对话 + 最近 5 个对话（已自动去重）
     [ 2] [置顶对话] 核心脚本设计方案  /89e3e40e31f2e3cf
     [ 3] [最新对话] 日常问题排查记录  /e7c84222cfc9b2c9

    第三组｜笔记本与收藏对话
     [ 4] [笔记本对话] 专题研究笔记大纲  /0123456789abcdef

    [C] 一键导出剪贴板里的 Gemini 链接并加入收藏
    [B] 启动带调试端口的 Chrome 浏览器
    [H] 从日常普通浏览器导出（拖入保存的 .html 文件，或直接回车读取系统剪贴板）
    [U] 输入新会话 / 笔记本 URL（导出成功后自动加入收藏）
    [Q] 取消退出

- **第一组**：当前受控 Chrome 窗口中已经打开的 Gemini 标签页，支持原地瞬间只读提取。
- **第二组**：自动从左侧边栏提取的全部置顶对话与时间最新的前 5 个对话。若某个对话同时处于置顶和最新前 5 名中，会自动去重合并为一条。
- **第三组**：保存在本地 `saved_notebooks.json` 中的 Gemini Notebook（笔记本）或常用收藏会话。由于 Gemini 网页端会将笔记本对话从主侧边栏列表中隔离，只需通过 `[U]` 或 `[C]` 导出过一次笔记本链接，后续即可在第三组中直接按编号导出。

## 普通浏览器免调试端口导出说明（选项 H）

如果你正在日常未开启调试端口的普通 Chrome 或 Edge 浏览器中浏览某段对话，无需重启浏览器，可直接使用 `[H]` 导出：

1. **方式一（保存网页文件）**：在浏览器对话页面按 `Ctrl + S` 保存为网页文件（`.html`），在工具菜单输入 `H` 后将 `.html` 文件拖入终端窗口回车。
2. **方式二（复制 DOM 节点）**：在浏览器按 `F12` 打开开发者工具（Elements 面板），右键顶层 `<html>` 或 `<body>` 节点，选择 `Copy` -> `Copy outerHTML`，然后在工具菜单输入 `H` 并直接按回车，工具会自动从系统剪贴板提取 HTML 结构并还原全部对话轮次与思考过程。

## 导出格式

简洁模式默认输出并覆盖桌面的：

    Gemini_Chat_Export.md

详尽模式默认输出并覆盖桌面的：

    Gemini_Chat_Export_Detailed.md

导出文件包含：

- 会话标题；
- 导出模式、来源渠道、导出时间与总轮次数；
- 按轮次组织的 `## 第 N 轮对话`；
- `### 用户` 消息代码块；
- `### 模型详细过程` 代码块（仅详尽模式且页面包含思考链节点时输出）；
- `### Gemini` 模型正式回复代码块；
- `## 未配对模型内容`（若页面存在独立于标准轮次之外的模型输出片段，将自动归档于文末，绝不静默丢弃）。

每条消息均使用动态长度的反引号围栏包裹（若正文中已包含三个反引号，外层围栏会自动升级为四个或更多反引号），确保粘贴到其他编辑器或模型对话框时格式完好。

## 本地缓存与配置文件

工具在运行目录下仅按需生成以下两个本地 JSON 文件（已默认加入 `.gitignore`，不会随仓库上传）：

    sidebar_cache.json
    saved_notebooks.json

- `sidebar_cache.json`：缓存最近一次扫描到的侧边栏置顶与近期对话列表（默认有效期 5 分钟，避免每次打开菜单都重新扫描）。
- `saved_notebooks.json`：保存用户通过 `[U]` 或 `[C]` 导出过的笔记本与收藏会话链接。

## 隐私和安全

- 本工具完全在本机运行，零第三方 npm 依赖。
- 严格采用 CDP `DOM` 与 `Target` 域只读提取，禁止调用 `Runtime.evaluate` 执行或注入任何网页脚本。
- 连续三次对全部对话节点执行长度与内容哈希快照比对，确保不会导出正在流式生成中的半截回复。
- 后台提取历史或笔记本会话时，自动在独立临时窗口中进行并在 `finally` 阶段自动关闭清理，不抢占用户当前键盘焦点。
- 导出的 Markdown 文件可能包含个人对话与代码内容，请妥善保管；提交 Issue 或 Pull Request 时请勿上传个人的 `sidebar_cache.json` 或 `saved_notebooks.json`。

## 常见问题

### 双击 `.ps1` 后被记事本打开

这是 Windows 对 PowerShell 脚本的默认安全策略。请双击运行同目录下的：

    运行-导出Gemini对话.cmd

### 提示“没找到 node 命令”

请安装 Node.js 22 或更高版本，并在重新打开终端后执行 `node --version` 确认版本号正常显示。

### 导出长对话或笔记本对话时等待了 20~40 秒

当导出未在当前标签页打开的历史会话或笔记本链接时，工具会在后台新建一个临时窗口等待云端对话正文渲染完成，并进行连续三次稳定快照校验，通常耗时 15 至 40 秒，导出完成后临时窗口会自动关闭。

### 超长历史对话只导出了下半部分

Gemini 网页端对超长历史对话采用向上滚动懒加载机制。为保证零干扰与节点稳定性，本工具不会自动在页面中模拟滚动。如需导出超长对话的最早期轮次，请先在浏览器页面中手动向上滚动至顶部等待历史加载完毕，再运行本工具导出当前标签页。
